门禁处置

未 ready 时收到 @ · 按状态分流
当前状态收到 @ 的处置理由
无流水线行 / ready 正常建任务，进入阶段 2 会话 不重跑阶段 0 / 1，已有结论直接复用
running 只打 eyes reaction，不建任务 避免两个任务并发写同一个会话
awaiting_info 回一条限速提示，把内容写入 tasks.supplement 评论优先：先当补充，再触发重跑；120s 冷却让位
blocked 回一条提示：回复 /recheck --force 不自动重跑，避免把失败循环放大
closed 静默忽略 不建任务、不回评论；reopen 由 GitHub 事件重新入队
classify/awaiting_info 只有 managers 的评论触发重分类 作者 / 他人评论只记录、不重跑
任意非 closed · managers /pipeline next / /pipeline prev blocked 时 next 等价解禁；记审计
